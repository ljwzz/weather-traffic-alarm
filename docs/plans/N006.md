# N006 天气预报地图

编写日期：2026-09-28。执行状态见 [总览](README.md)。实现依赖 N003 及下述外部条件；关联 T090–T097、T112A、T114、T131。资料核实可提前进行。

## 当前实现与目标

[WeatherScreen](../../android/app/src/main/java/com/ljwzz/weathertrafficalarm/ui/zhitu/ZhituScreens.kt) 当前显示通勤天气摘要；[WeatherProvider](../../android/core/model/src/main/java/com/ljwzz/weathertrafficalarm/core/model/WeatherProviders.kt) 输出双地点天气评估。[AmapMap](../../android/core/map/src/main/java/com/ljwzz/weathertrafficalarm/core/map/AmapMap.kt) 当前处理点位、路线和路况，尚无天气图层输入。

2026-09-28 实读 Figma 目标包含降水图层、强度图例、通勤路线、未来两小时时间轴及数据来源；画板注明演示雨区。原始节点：https://www.figma.com/design/wN04BlxRelbJyBVF35DyXE?node-id=223-3721 。

目标：在原生天气详情中展示有真实来源及有效时间的降水预报地图，与现有路线及天气预览共存。页面刷新和图层播放只读取数据，不创建评估决策或更改闹钟。

## 阶段 A：外部前置条件

| 条件 | 必须取得的证据 | 未满足时的处理 |
|---|---|---|
| 账号权限 | 企业雷达实况／预报接口授权、可用区域、配额、展示许可与来源标注要求 | 图层任务登记阻塞，现有普通天气摘要继续可用 |
| 鉴权 | 目标接口的凭据类型、请求认证方式、错误模型；实际账号调用成功记录 | 不把现有 v2.6 连接成功当作雷达权限证明 |
| 安全传输 | API 和返回图片均存在可用 HTTPS 链路，重定向和下载主机可验证 | 禁止降级到明文；条件未关闭前不接真实图层 |
| 坐标与投影 | 查询输入基准、图像边界顺序、输出坐标基准、投影及高德叠加校准 | 保留具体缺项，不凭两地天气结果推定图层位置正确 |
| 数据时间 | 帧时间、实况／预报区别、更新频率、有效期及无覆盖语义 | 不生成伪预报帧，不将缺少覆盖显示为晴天 |

彩云雷达文档将该接口列为企业套餐增值服务，并提供图片时间与边界；图片边界为 WGS84，顺序为南、西、北、东，叠加高德底图须处理坐标差异。文档示例含 HTTP 地址，示例本身不能证明 HTTPS 可用。以上于 2026-09-28 联网核实：https://docs.caiyunapp.com/weather-api/v1/6-radar.html 。本项目 Manifest 当前禁用明文流量，代码依据：[AndroidManifest](../../android/app/src/main/AndroidManifest.xml)。

实际账号是否具备雷达权限、完整 HTTPS 链路及查询输入基准，信息不足，无法验证。雷达图像输出的说明不等于普通 v2.6 天气查询输入基准已确认；原 [SPEC 第 14 章](../../SPEC.md)／T097 的条件单独跟踪。2026-09-28 核实的常见问题页：https://docs.caiyunapp.com/weather-api/v2/v2.6/tables/q.html 。

阶段 A 交付协议确认表、脱敏成功／失败样例、区域校准结果和放行结论。全部必要条件成立后进入阶段 B。

## 阶段 B：接口与界面方案

以下为项目实施方案：

| 拟新增对象 | 职责与最小契约 |
|---|---|
| `WeatherMapProvider` | 获取指定视野及时间范围的雷达帧；独立于现有 `WeatherProvider.evaluate` |
| 图层请求 | 明确坐标基准的范围、请求时间窗口及非敏感凭据版本；凭据明文仅由 Provider 内部读取 |
| 帧集合 | 帧 ID、有效时间、实况／预报类型、边界、坐标／投影、来源及整体有效期；带鉴权的下载 URL 不进入页面状态或日志 |
| `WeatherMapUiState` | 未配置、无权限、加载、成功、有效缓存、无覆盖、错误；分别保存当前帧、时间轴、图例和来源 |
| 地图适配层 | 增加受生命周期管理的降水图层输入，与现有路线／标记共存；销毁时取消下载并释放图像 |

雷达凭据按已确认的鉴权契约使用独立可选存储及版本，复用现有加密机制，新增时保留普通天气凭据。如接口确实需要独立 token，新增专用配置入口；现有四字段开发导入协议不隐式清空新凭据。发布实现前将确认后的字段和清除行为写入配置文档。

页面默认显示当前可用的最新实况帧，再按响应实际时间向后展示至多两小时的预报。支持手动选时、播放／暂停；不强制凑满固定帧数。时间轴缺段明确可见，降水单位、色标、来源和更新时间来自已确认契约。按官方数据边界处理投影及重采样，不能将演示雨区或任意拉伸图片作为准确叠加。

复用通勤地点和已选路线，加载天气图层不改变选中路线。天气地图入口接入现有天气详情导航：首页进入返回首页，设置进入返回设置。没有高德授权或原生渲染不可用时，保留可用摘要并显示真实原因。

缓存键包含区域、图层类型、时间范围和凭据版本。默认内存复用最多 5 分钟，且不超出供方有效期／预报末帧；供方要求更短时取更短值。刷新失败只保留仍有效的同输入缓存并标记来源。移动视野／更换地点／替换凭据时取消旧请求；旧响应必须经过输入和代次校验。播放在页面不可见时停止，不开启后台定位或常驻图层刷新。

## 任务拆分与验收

1. 完成阶段 A，在规格中维护可复核的协议来源与授权前置条件。
2. 定义独立 Provider、请求／帧契约、凭据隔离及错误模型，增加受控响应测试。
3. 扩展地图适配层，实现图像下载、校准、帧切换和资源释放。
4. 接入天气详情、时间轴、图例、缓存和失败状态；校验首页预览与自动评估的数据隔离。
5. 在 N003 已验证地图能力的设备上执行真实图层验收，更新规格和来源说明。

| 场景 | 验收要求 |
|---|---|
| 成功 | 真实雨区、路线和公开控制点位置正确；帧时间、来源、图例与服务响应一致 |
| 失败 | 无雷达权限、鉴权错误、限流、图片失效、无覆盖及断网独立显示，不伪装为无降水 |
| 缓存 | 有效旧数据标明缓存；过期、区域变化和凭据替换后旧帧不能复用 |
| 并发与生命周期 | 快速拖图／选时、重复刷新、旋转及前后台切换没有旧响应覆盖、重复请求或资源泄漏 |
| 调度隔离 | 浏览、刷新和播放前后计划、决策、闹钟实例及注册状态不变 |
| 协议边界 | 图片 URL 的 HTTPS 与重定向校验、无效边界、乱序／重复／缺失帧及时间窗口截断均有测试 |
