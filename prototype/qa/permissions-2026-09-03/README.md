# 权限原型浏览器验收

日期：2026-09-03。环境：`http://127.0.0.1:4173`，412 × 892 移动端视口。仅验证本地离线原型的可见页面和交互，不构成 Android 或小米系统权限验收。

## 已验证

| 场景 | 结果 |
|---|---|
| 工具栏与设置页 | 场景、设备和设置入口工具栏位于手机画面外。通用 Android 仅显示合并的响铃显示项和位置状态，不显示小米专属项；切换到小米后，锁屏显示与后台弹出界面立即显示，并带当前“待手动确认”状态。 |
| 通用 Android | 通知、精确闹钟、全屏提醒和位置均显示用途说明与状态；“去设置”仅为离线模拟。 |
| 小米 | 锁屏显示和后台弹出界面均显示用途；手动确认后为“用户已确认 · 未自动核验”。长状态与“入口不可用或未找到”提示换行后完整可见。 |
| 诊断页布局 | 页面可滚动到底部；位置说明与“重新检查（演示）”未被底部手势区遮挡。 |
| 系统入口不可用 | 切换“入口不可用或未找到（演示）”后，所有相关项显示该状态，不再提供误导性的设置跳转。 |
| 首次启用引导 | 保存启用闹钟后出现“完善响铃显示设置”；引导正文和三项操作完整可见。 |
| 定位 | 仅点击“使用当前位置（仅本次）”后展示定位选择；拒绝、大致位置、精确位置和定位服务关闭为离线可选状态。 |
| 控制台 | 已检查的流程无 warning 或 error。 |
