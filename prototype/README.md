# 知途本地原型

## 运行

在仓库根目录执行：

```bash
node prototype/server.mjs
node --test prototype/tests/*.test.mjs
```

浏览器打开 [本地原型](http://127.0.0.1:4173/#/home)。服务只监听本机回环地址。

## 当前交互

- 首次数据为空；可添加、编辑、启停和删除多个本地闹钟。
- 闹钟支持指定日期单次、每周重复和工作日；默认是未来的单次 `06:00`。
- 可编辑名称、日期/时间、铃声、振动和 1–30 分钟贪睡；数据持久化到浏览器本地存储。
- 日历以设备当前月份打开；单日覆盖使用 `计划 ID + 日期` 保存，只影响当前计划和选定日期。
- 记录显示本机保存、启停和异常事件；首次为空。
- 常用地点文字与出行方式可本地保存，不请求定位或地图服务。
- 天气图、地图和路线容器保留原有页面结构，显示“暂未接入”，不展示模拟天气、距离、耗时、路况或提前计算结果。

## 边界

- 本原型不会注册系统闹钟、响铃、振动、读取权限或打开系统设置；这些由 Android 应用的 `LocalAlarmCoordinator`、Receiver 和响铃服务实现及验收。
- 凭据只保留当前页面会话，刷新即清空；浏览器原型不进行连接测试，也不输入真实密钥。
- 日历页面当前按星期判定工作日。节假日数据接入、缓存和校验由 Android 实现。

## 开发与验收约束

后续开发和界面验收必须参照本地原型，包括页面结构、布局、组件、文案及交互。除非用户明确要求修改，不得自行调整原型或另行设计。非视觉业务与安全规则以 `SPEC.md` 为准；发现冲突时先向用户确认。
