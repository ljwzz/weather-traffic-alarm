# 知途本地原型

当前 Figma 页面级参照：[`知途 · 完整设计`](https://www.figma.com/design/wN04BlxRelbJyBVF35DyXE?node-id=218-2464)。原型页面与交互仍以本目录可运行内容为准。

## 运行

在仓库根目录执行：

```bash
node prototype/server.mjs
node --test prototype/tests/*.test.mjs
```

浏览器打开 [本地原型](http://127.0.0.1:4173/#/home)。服务只监听本机回环地址。

## 当前交互

- 凭据页两项测试均为“测试连接”；高德直接检查当前演示输入，彩云按凭据 fixture 验证且独立于通勤地点；结果使用成功／失败配色的横幅，60 秒后自动关闭。

- 首次数据为空；可添加、编辑、启停和删除多个本地闹钟。
- 闹钟支持指定日期单次、每周重复和法定工作日；默认是未来的单次 `06:00`。选择法定工作日后，显示连续四周的 28 天预览。
- 可编辑可选备注、日期/时间、铃声、振动和 1–30 分钟贪睡；时间使用可跨界循环的小时/分钟滚轮，12 小时制增加 AM/PM；编辑页及选择页动态显示下次响铃倒计时。数据持久化到浏览器本地存储。
- 日历以设备当前月份打开；单日覆盖使用 `计划 ID + 日期` 保存，只影响当前计划和选定日期。
- 记录显示本机保存、启停和异常事件；首次为空。
- 首次启动可同意高德授权或仅用基础功能；Web Service Key 与 Android SDK Key只保留当前页面会话。
- 全局通勤可被单个闹钟覆盖；地点页展示输入提示／POI、地图选点和“使用当前位置”入口。定位仅响应单次点击。
- 地点搜索输入非空且加载 fixture 生效时，搜索框内右侧展示加载图标。
- 首次启用闹钟会展示通知、精确闹钟、全屏提醒、锁屏显示和后台弹出页面的可靠性准备状态；缺失能力说明后仍可继续启用。Android 标准授权、系统设置跳转与返回状态，以及小米两项的手工设置和用户确认均有离线演示。
- 当前位置在用户点按入口后才进入前台定位演示，并分别展示精确、粗略和拒绝结果。权限演示工具栏可切换设备与场景。
- 设置页提供提醒权限与诊断，以及通勤地点与路线、工作日日历、数据与凭据、隐私与地图授权的独立入口，并展示 App 图标、版本及构建号。天气缓冲使用独立页面，工作日、周末、法定休息日分别编辑并保存，三级均须为 0–60 分钟整数。
- 权限演示的运行时状态和待续操作只保留当前页面会话；同一会话内，明确点按继续启用后，同一缺失状态不再重复提示。返回保留闹钟编辑草稿，取消不写入计划或引导结果，也不消费确认；后续主动保存仍需确认，继续操作按当前计划和会话幂等。
- 地图与路线通过确定性视觉 fixture 展示成功、加载、无 Key、定位拒绝、服务错误与原生渲染不可用；成功状态提供驾车、公交、步行、骑行、电动车五种路线、最多三条备选与当前路况。
- 高德地图和路线使用确定性离线 fixture；彩云天气可切换加载、成功、缓存与错误 fixture。原型不发送真实 API 请求、不展示坐标，也不保存彩云 App Key 或 App Secret。
- 首页按“天气 → 自动评估 → 闹钟 → 路线”展示。天气与路线卡在进入、返回首页和页面恢复时检查本地 fixture；可下拉 72px 或点按“刷新通勤预览”同时强制刷新，两项请求独立且重复操作合并。刷新不创建评估结果、不改写闹钟或本机记录。
- “数据与凭据”可切换首页配置读取（含读取失败）、天气凭据／连接测试、天气结果、地图 SDK 与路线 Web fixture。天气成功摘要为天气等级、通勤起终点、数据时间和来源；路线成功摘要为出行方式、距离、耗时、通勤起终点、数据时间和来源。首页结果卡与详情页共享同一预览；配置保存、清空或全局通勤保存后使旧预览失效。天气 fixture 使用独立时钟和预报有效窗口，过期结果不会作为可复用数据。
- Android 彩云天气实网与界面验证记录见 [`../android/qa/caiyun-device-2026-09-02.md`](../android/qa/caiyun-device-2026-09-02.md)。原型使用离线 fixture 演示自动评估状态；真实自动评估与闹钟调度由 Android 实现。
- 首页本次评估、计划关联摘要和决策记录均以明确的 `decisionId` 打开详情。详情使用该记录保存的计划快照、评估输入、调度应用结果与实例关联；计划后续编辑或删除不会改写已展示的 fixture 记录。失败、截止和过期详情只显示该记录存在的失败／降级／重试字段，缺失关联显示空态。
- 响铃离线演示使用两个独立全屏路由：`ringing-basic` 为 `2026-09-02 07:30` 的基础闹钟 fixture，`ringing` 为 `07:18`、提前 12 分钟的提前 fixture。两者初始贪睡均为 10 分钟；贪睡时长校验为 1–30 分钟整数。
- 提前响铃在锁屏模拟页只显示“解锁后查看提前原因”。解锁后的详情以当前 `occurrenceId` 的根实例和 `decisionId` 定位同一离线决策；贪睡子实例保留根实例关联。查看详情不执行停止、贪睡、网络请求、计划写入或调度操作。
- 停止和贪睡在原响铃路由展示结果。停止态仅提供“返回闹钟／重新演示”；贪睡态仅提供“返回闹钟／模拟再次响铃”。贪睡产生独立演示子实例，基础与提前 fixture 的首次再次响铃分别为 `07:40` 与 `07:28`；二次贪睡继续递增。重复操作按实例 ID 幂等；离开重进、重置或刷新会重建演示会话。

## 边界

Android 已接入真实基础／贪睡响铃页面，验收与 APK 见 [`原生响铃记录`](../android/qa/native-ringing-2026-09-02/README.md)。原生结果页为“返回闹钟／关闭”，与以下离线演示按钮语义分开。

- 本原型不会注册系统闹钟、播放音频、振动、读取权限或实际打开系统设置；所有系统设置跳转均为离线状态演示。基础／提前响铃仅为离线交互 fixture。演示不写入 `alarmPlans`、`alarmEvents` 或 `dateOverrides`，也不发网络请求。Android 基础本地闹钟的注册、响铃、停止与贪睡由 `LocalAlarmCoordinator`、Receiver 和响铃服务实现及验收；提前 fixture 不代表自动提前已启用。
- 凭据页面只用于本地 fixture 测试：不进行网络连接测试；彩云 App Key 和 App Secret 不在原型中采集或保存。高德演示输入仅保留当前页面会话，刷新即清空。
- 首页 fixture 操作：在“数据与凭据”将天气凭据 fixture 设为已配置，并填写任意高德 Web 演示值；保存全局起点和终点后返回首页，展示成功摘要。把天气 fixture 设为“缓存数据”展示本地缓存来源；把路线 Web fixture 设为“请求失败”或天气 fixture 设为“服务错误”，再返回首页或刷新，可展示各自失败状态和有效旧摘要。浏览器控制台也可调用 `window.ZhituPrototype.setHomePreviewFixture(...)` 与 `window.ZhituPrototype.refreshHomePreview()` 进行离线验收。
- 日历和工作日闹钟在 2026 年使用离线节假日与调休 fixture；其他年份按星期判定。节假日数据接入、缓存和校验由 Android 实现。

## 开发与验收约束

后续开发和界面验收必须参照本地原型，包括页面结构、布局、组件、文案及交互。除非用户明确要求修改，不得自行调整原型或另行设计。非视觉业务与安全规则以 `SPEC.md` 为准；发现冲突时先向用户确认。
