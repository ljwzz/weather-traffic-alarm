## 状态保留与边界

### 获准临时切换后的补充验证

- 通知：重置为未授权后，启动应用未自动弹窗；从诊断项触发系统授权。拒绝后显示恢复提示，再次进入系统通知设置并开启，返回读取为已开启。[系统申请](./notification-request.png)、[拒绝结果](./notification-denied.png)、[系统设置](./notification-settings-denied.png)、[恢复结果](./notification-restored.png)。
- 小米：两项均可切换为拒绝；拒绝后台弹出界面后，全屏 AppOps 变为 ignore，应用读取为未补齐。[两项拒绝](./xiaomi-display-denied.png)、[全屏降级](./fullscreen-denied-diagnostics.png)。只重新开启全屏提醒时，后台弹出界面仍为拒绝，需另行恢复，不可仅凭全屏状态推断其授权。[现场状态](./fullscreen-restored-background-still-denied.png)。随后通过小米权限页恢复了两项始终允许并留图。[恢复截图](./xiaomi-display-restored.png)。
- 位置：真实地点页显示尚未授予；主动点击后先展示用途说明，再出现包含模糊／精确位置的系统授权弹窗。拒绝后出现“请在设置中开启位置权限”和恢复入口，并成功打开本应用系统详情页。用户补充截图再次确认系统申请已触发，不能将“启动时不自动申请”解释为按钮不申请。中断前未完成设置授权返回后的单次定位续办观察，不计为通过。
- 在用户中断验证并补充截图后，再次读到权限状态发生变化；已将通知恢复 granted + USER_SET、精确位置 granted、粗略位置 denied、全屏 UID allow。位置权限保留系统本次选择精度的内部标记 `524288`，未使用全局权限重置。
- **恢复核对待完成**：手机现处于锁屏，小米两项需要解锁后再次检查并恢复；不将中断后的最终状态计为已全部恢复。

### 首轮未切换权限的边界记录

- 结束后再次读取：通知、精确位置、粗略位置、精确闹钟、全屏提醒和定位服务状态均与预检一致，无本应用活动响铃服务。
- 没有切换系统权限、音量或定位服务，没有提交或删除闹钟；只完成会话内的两项手工确认。现有应用数据保留，手机保留最新 APK。
- 本轮通过的是当前已授权状态下的入口、展示、返回和取消流程。首次申请、拒绝后恢复及权限关闭后的行为，需要用户同意临时调整权限后继续验证，不能计为本轮已通过。
- 本轮没有读取实际坐标或触发定位客户端；精确位置状态仅通过系统授权状态及应用显示交叉核对。
